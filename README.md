# Gidan Wereda Digital Governance & Service Portal

This is a full-stack web application developed for the Gidan Wereda Administration Office to manage digital services, staff operations, and public administration tasks efficiently.

## 🛠 Tech Stack 
- Frontend: React.js, HTML, CSS, JavaScript, Bootstrap
- Backend: Node.js, Express.js
- Database: MySQL
- Security: Bcrypt (for secure password hashing)
